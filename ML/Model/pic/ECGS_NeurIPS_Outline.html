Related Work  ~0.6页 · 可移入附录
材料充分 ▼
三条分支 + 与ECGS的区别
  • ① 对抗训练主线：PGD-AT / TRADES / MART — 需要内循环攻击，overhead = K×(F+G)；ECGS无此成本
  • ② 不确定性引导训练：EUAT / CLUE — 使用完整 PE（O(BC) 额外运算，需要 MC dropout/集成）；ECGS 用 pmax 替代，O(B) 额外运算
  • ③ 损失重加权 / Curriculum：Focal Loss, Self-paced Learning — 都关注"困难样本"，但 ECGS 关注的是"自信且错误"样本（不是简单的 hard example mining）
  • ④ Corruption robustness：AugMix / DeepAugment — 专注数据增强；ECGS 无需改变数据分布

Method  ~2页 · 核心贡献
材料最充分 ▼
3.1 Problem Setup
  • 符号：logits x, targets y, batch B, classes C
  • 定义"自信且错误"样本的形式化
  • pmax = max_c softmax(x)_c 作为 confidence 代理
3.2 ECGS Core Mechanism
  • Confidence gate: σ(k(p_max − τ))
  • Wrong gate: 1 − p_y（真类概率的补）
  • Scale = 1 + λ · g_conf · g_wrong
  • 梯度放大通过 ScaleGrad（自定义 autograd Function）实现
  • 前向不变，只改反向传播
3.3 Auto-ECGS
  • 固定 k=20（anti-oscillation，实验验证）
  • 动态 τ：τ_t = Quantile(p_max, q_t) — 自适应 batch 分布
  • auto_q：q 从 q_start 线性升至 0.9（早期宽，后期窄）
  • auto-λ：基于 gate EMA，clip(δ/g_ema, 0, λ_max)
  • 最终只剩 1 个参数：τ_start（即 q_start ∈ [0.60, 0.90]）
3.4 pmax vs PE：充分性分析
  • 理论论证：pmax 包含 PE 的关键控制信号
  • 实验：pmax 与 1-PE 曲线的对比（Attachment 4 的图）
  • 实践意义：pmax O(1) per sample 而 PE 需要 O(C)
3.5 Complexity Analysis
  • Time: ΔTECGS = O(B log B)（quantile 排序主导）
  • Space: ΔSECGS = O(B)（batch-level vectors）
  • 对比 PGD-AT: ΔT = O(K(F(B)+G(B))) — 差 ~10-40× 量级
  • 理论最优复用口径下 O(BC) 张量可复用，不额外计算
建议：用一个小 Table 或公式框并排展示 CE / ECGS / PGD-AT / TRADES 的复杂度对比，直观冲击力很强

Analysis  ~0.5页
需要补充理论论证 ▼
  • 为什么没有 Trade-off？ECGS 只在反向传播阶段 scale 梯度，前向 loss 不变 → clean distribution 的优化路径不被扭曲
  • 为什么 pmax 足够？pmax 是 softmax 最大值，隐含地编码了 all-class margin 信息；与 PE 的相关性分析
  • 为什么曲线分离快？ECGS 在 epoch 5 就能分离，而 PGD-AT 需要 warmup 才能压低 STD/Error → 梯度信号更清洁
  • Scale 的几何意义：将高置信错误样本往决策边界"推回"，加强边界处的几何结构
NeurIPS 建议：如果有理论 Proposition（哪怕是 heuristic 的），放在这里会显著提升分数。可以尝试证明"在 linear model 下，ECGS 收敛到更大 margin 的解"作为 toy theorem。

最后写 ▼
  • 总结 ECGS 的核心贡献：pmax-based gradient scaling + Auto-ECGS + 无 trade-off 的 robust 提升
